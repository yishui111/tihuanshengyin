# 功能D · GPT-SoVITS 换声服务接口文档

> 适用版本：2026-09-23（已实测冒烟通过：单角色转换、跨角色切换、CUDA 推理）
> 服务定位：给视频配音用的"逐段换声"引擎。输入一段人声，输出目标角色音色的同内容语音。

## 一、部署与启动

| 项 | 值 |
|---|---|
| 服务脚本 | `gptsovits_service\gptsovits_cn_api.py`（自研封装，上游引擎在 `gptsovits_service\GPT-SoVITS\`） |
| 启动方式 | 仓库根目录 `start.bat D`（或单独 `runtime\py312\python.exe gptsovits_cn_api.py`） |
| 默认端口 | 8040（环境变量 `API_PORT` 可覆盖；被占用自动顺延） |
| 运行时 | `runtime\py312`，需 NVIDIA 显卡 |
| 角色权重 | `gptsovits_service\models\<角色>\`（`*.ckpt` + `*.pth` + `ref.wav` + `ref_text.txt`） |

本机（2026-09-23）实际已部署权重的角色：**ayaka、azhong、dabing、liejun、songwukong、testnv**。
`GET /models` 会列出全部已注册角色名，但其中 fengyanlin/keai/laolei/liuyanhua/wangyou1
本机暂无权重，调用会失败——部署新角色即自动可用。

## 二、接口约定

- 全部接口为 HTTP + JSON/UTF-8；转换类接口是 `multipart/form-data` 上传。
- 输出音频固定 **wav、32000Hz、单声道**。
- 服务内部是**全局串行锁**（同时只处理一个请求，多说话人请逐段排队调用），切换角色权重约 3~10 秒，同角色连续调用约 1~3 秒/段。
- 合成文本上限 500 字（超长请先切句）。
- 本机自测请用 `curl --noproxy "*"`（绕开代理）。

## 三、接口明细

### GET /health

```json
{"status": "ok", "service": "gptsovits-cn", "device": "cuda:0"}
```

### GET /models

```json
{"models": ["ayaka", "azhong", "dabing", "liejun", "songwukong", "testnv", "..."]}
```

### POST /convert —— 素材换声（ASR + 重合成）

流程：上传一段人声 → SenseVoice 识别成文本 → GPT-SoVITS 用指定角色音色重新合成。
**语速/感情来自该角色自己的参考音频（models/<角色>/ref.wav），不是上传的素材。**

请求（form-data）：

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| audio | file | 必填 | 素材音频 wav/mp3/m4a，须是清晰人声 |
| character | text | ayaka | 目标角色名，见 `GET /models` |
| speed | number | 1.0 | 合成语速倍率 |
| top_k | int | 15 | 采样参数，一般不动 |
| top_p | number | 1.0 | 采样参数 |
| temperature | number | 1.0 | 采样参数 |

```bash
curl --noproxy "*" -X POST http://127.0.0.1:8040/convert \
  -F "audio=@segment_01.wav" -F "character=songwukong" -o out.wav
```

响应：`200` 返回 wav 文件流；错误为 JSON：

| 状态码 | 含义 |
|---|---|
| 400 | character 名称不合法 |
| 404 | 角色不存在（或本机未部署该角色权重） |
| 422 | 素材里没识别到人声内容 |
| 500 | 推理失败（看服务日志） |

## 四、面向"视频逐段换声"的扩展规范（待实现）

当前 `/convert` 的感情/语速来自角色自带参考音，**不跟随原视频说话人**；且合成时长
不等于素材时长（句子是"重新说一遍"的）。要做视频配音（对口型、保感情），需实现：

1. **`ref_from_input`（bool，默认 false）**：为 true 时用上传素材本身作合成参考音频
   （GPT-SoVITS 的 `ref_wav_path` 传上传素材，`prompt_text` 用同段 ASR 结果），
   输出的语速与感情即跟随原句，音色仍由目标角色微调模型决定。
   ⚠️ 参考音频说话人与角色模型训练人不同，音色可能轻微"串味"，需按角色试听定开关。
2. **`target_duration`（number，秒，可选）**：合成结果做不变调变速（WSOLA）对齐到该时长，
   供拼接回原视频时对齐口型。调用方传原段时长。
3. 调用方（hub 批量管线）约定：逐段串行调用；每段为一句或一个换气内的话，超 500 字先切；
   段边界比 VAD 边界外扩 150~200ms；笑声/叹息/纯噪声段不送合成、直接保留原声。

## 五、已知限制（调用前必读）

- 句子是重新合成，**时长不保证一致**（对齐口型依赖 `target_duration` 扩展）。
- 两人重叠说话的段无法处理，只能整段保留原声或只换其中一人。
- 笑声、咳嗽、喊叫等非语言声重合成后会失真，建议原声直通。
- ASR 识别错的字会以错误内容"重新说一遍"（合成忠实于识别文本）。
